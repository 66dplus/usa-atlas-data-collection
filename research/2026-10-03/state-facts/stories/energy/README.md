# Электричество и стоимость жизни

Четыре датированных сюжета, проверенных по EIA. Две истории сравнивают бытовую цену с потреблением и средним счётом; предварительная цена всех секторов хранится отдельно. Четвёртый сюжет явно обозначен как исторический прогноз для энергосистем.

Исходные PDF/XLS и государственные HTML сохранены с HTTP receipts и SHA-256. `selected-evidence.json` содержит точные XLS ячейки для шести выбранных штатов, извлечённые стандартной библиотекой Python из XML внутри XLSX.

Повторять сверку после обновления официальной страницы `sales_revenue_price` в октябре 2026; новый выпуск нельзя молча переписать поверх исторической истории.
