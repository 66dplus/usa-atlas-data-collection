## Очистка БД остановилась

Полностью скопированы 49 206 438 строк всех девяти источников. Полные контрольные
суммы исходных и восстановленных записей совпадают. Exact comparison завершила
7 из 102 диапазонов, во всех семи 0 расхождений, затем остановилась на диапазоне
`06 <= geo_id < 07` в 19:26 UTC 28 сентября.

Причина из PostgreSQL stderr: при расширении сегмента shared memory до
268 435 456 байт получен `No space left on device`. Это ошибка общей памяти
контейнера во время запроса, не подтверждение заполнения диска базы.

Переключение не выполнено, исходная таблица не удалена, `result.json` отсутствует.
Экономия места в БД пока не достигнута: новая компактная копия занимает место
рядом с исходной. Резервный архив 592 524 948 байт ранее прочитан и проверен.

В `database/cleanup_storage.py` подготовлено изменение exact comparison:
`max_parallel_workers_per_gather=0`, `enable_parallel_hash=off`. Оно исключает
parallel hash shared-memory allocation, сохраняя точное сравнение и ограничения
временных файлов. Изменение ещё не исполнялось на PostgreSQL.

Перед продолжением нужно решить также старый backup binding: текущий
`backup.json` создан первым процессом и не содержит `source_fingerprint_sha256`;
новый runner намеренно не принимает такой архив для автоматического reuse.
Нельзя просто дописать привязку без проверки исходного снимка. Процедура
восстановления описана в предыдущем CLEANUP-OPERATIONS.md.
